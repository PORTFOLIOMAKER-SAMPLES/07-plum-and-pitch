**Home** — 히어로 아래에 숫자 지표와 자주 쓰는 원료 9종, 향 9종 갤러리, 만드는 방식, 3D 황동 화병, 원료 마퀴, 구독 CTA.
**Notes** — 배합 원칙, 그리고 **버린 이유 5건**.

## 만든 것보다 버린 것을 더 자세히

카드마다 향의 구성(탑·미들·베이스)만 적으면 카탈로그가 됩니다.
그래서 각 향에 **왜 그렇게 만들었는지 · 어디서 틀렸는지 · 몇 번 다시 잡았는지 · 손목에서 몇 시간 가는지**를 함께 적었습니다.

> 04번은 첫 배치를 전부 버렸습니다. 비누 같다는 평이 여섯 명 중 다섯이었습니다.
> 알데하이드를 0.3% 단위로 다시 잡고 나서야 통과했습니다.

`Notes` 페이지의 **버린 것들**은 실패를 다섯 가지 원인으로 분류한 기록입니다 — 재료 과다 / 시향지에서만 좋음 / 농도 오판 / 계절 미고려 / 산지 변경. 낸 향 9종에 폐기 시제품 214개라는 숫자를 함께 두었습니다.

## 직접 열어서 뜯어보기

1. [portfoliomaker.site](https://portfoliomaker.site) 접속
2. 상단 **저장 · 불러오기** 아이콘 클릭
3. **파일에서 불러오기** → 이 저장소의 `plum-and-pitch.pbproj` 선택

## Portfolio Maker 는 어떤 도구인가요

- **설치 없음 · 가입 없음** — 브라우저에서 바로 시작합니다
- **틀 → 내용 → 꾸미기 → 내보내기** 네 단계로 끝납니다
- 테마 18종, 글꼴 10종, 파트 15종 이상을 조합합니다
- 3D 모델(`.glb`) 뷰어, 무료 사진 검색, 다크/라이트 토글이 기본 제공됩니다
- 결과물은 **단일 HTML** 또는 **폴더 ZIP** 으로 내려받습니다 — 이 저장소가 그 ZIP 그대로입니다
- 만든 프로젝트는 `.pbproj` 로 저장해 두었다가 언제든 다시 불러옵니다
